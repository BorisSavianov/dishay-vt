# ML predict path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train a tabular model in Python, export it to JSON, serve predictions from the existing Next.js app to web and mobile.

**Architecture:** `ml/` (pandas + scikit-learn) owns preprocessing (hand-written, exportable), training, evaluation and export to `web/src/model/model.json`. `web/src/lib/ml/` re-implements preprocessing and inference in TypeScript; `/api/model` and `/api/predict` serve it. A parity fixture generated by Python proves TS == sklearn.

**Tech Stack:** Python 3.12+ via uv (group `ml`: pandas, scikit-learn, openpyxl, pytest), Next.js 15 / TypeScript / Vitest.

**Spec:** `docs/superpowers/specs/2026-11-19-ml-predict-design.md`

## Global Constraints

- `pipeline/` stays standard library only; ML deps live in the uv dependency group `ml`.
- Supported estimators: DecisionTree, RandomForest, ExtraTrees, GradientBoosting (regressor + classifier), LinearRegression/Ridge, LogisticRegression.
- Tree inference compares `Math.fround(x) <= threshold` (sklearn casts X to float32).
- Routes follow the repo convention `/api/*` (no `/api/v1`); errors are `{ok:false, error:{code, message, details?}}`.
- `/api/predict`: 1–100 rows, body ≤ 32 KB (413), unknown feature → 400, missing optional feature → imputed.
- The fixture model is `kind: "fixture"` and the UI says so; never present it as a real result.
- Files in `mobile-kit/ml/` are byte-identical copies of `web/src/lib/ml/{types,client,usePrediction}.ts`.
- No secrets in client code; CORS `*` on the two ML routes only (no cookies, no keys).

## Review Focus

- Numeric strings from mobile TextInput ("12,5") → parsed as 12.5, not rejected. Test in Task 2 (`validate.test.ts`).
- Unseen category value → encoded as `__other__` (or all zeros) with a warning, not a 500. Task 2.
- Empty array, 101 rows, non-object row → 400 with a row index. Task 2.
- Classification labels that are numbers in the CSV (0/1) → strings in JSON, argmax tie → first class. Task 1 + parity.
- Bulgarian CSV (`;` separator, decimal comma, cp1251) loads with correct numeric dtypes. Task 1 (`test_data.py`).
